# Runtime Self-Learning v6.0.0

面向 HanaAgent 1.1.24-beta 的 v2 App。使用官方 SDK 与隔离数据目录，提供工作流观察、经验检索、审核、健康检查及相关提示注入。

## 安装

1. 下载 `app-hanako-runtime-learner-6.0.0.zip`，在 Hana 的“扩展 → 本地安装”导入，完成声明能力审查。
2. 停用旧 v1，避免重复采集。可以直接从空数据开始；如需保留旧记录，先阅读源码中的迁移说明。
3. 设置入口：左下角齿轮 → 应用 → 自学习。模型功能使用 Hana 的工具模型，默认关闭；后台计划须显式 enable。

普通用户无需安装 Node 或 npm。配套 `.entry.json` 供市场登记使用；GitHub 自动生成的源码 ZIP 不是安装包。
