# Runtime Self-Learning 6.2.0

**让长期记忆可管理、可追溯，也能按项目正确调用。**

> **发布状态：候选版本，尚未公开发布或安装到生产 Hana。**目标宿主为 HanaAgent 1.3.6-beta。本文描述本地候选的实际能力，不代表已完成生产验收。

## 这版解决什么

长期记忆的价值不只是保存更多内容，还要能知道系统记了什么、记忆来自哪里、信息是否仍然有效，以及当前项目能否安全地用到它。6.2 在 6.1 的人工管理与事实时间线基础上，补齐来源追踪、分层检索和跨项目边界。

## 主要变化

- **查阅和维护记忆**：可以按项目、类别和关键词搜索，查看记忆正文、修订历史与来源；支持新增、编辑、逻辑删除和导入导出。
- **追到来源与时间**：学习回合生成不含原始对话正文的 episode 摘要；事实记录有效时间与系统获知时间，修订时保留新旧关系。
- **分层而不是一股脑注入**：稳定偏好、事实和项目状态属于 core；过程经验等放在 archive。自动提示只使用已批准、范围匹配的核心记忆，并受提示预算约束；归档记忆可显式搜索。
- **本地多信号召回**：在 CJK BM25 和多查询融合上增加显式实体/关系与字符 n-gram 信号，帮助中英别名、短词和拼写变化时找回相关项。这不是神经 embedding，也不调用云端向量服务。
- **加强项目隔离**：未知项目范围不会退化成读取所有项目；查看、写入、导入和导出都受当前项目范围限制。

## 数据与隐私

插件数据由 Hana 放在同一 `<HANA_HOME>` 下的 `app-data/hanako-runtime-learner/`；程序本身位于宿主管理的只读 `apps/hanako-runtime-learner/`。升级包替换程序目录，卸载默认保留数据目录。备份时以插件返回的 `dataDir` 为准。

插件不默认调用模型或访问网络。需要模型整理时必须在设置中显式开启，使用 Hana 的工具模型。删除是逻辑隐藏，不会安全擦除旧学习日志或用户以前导出的备份。

## 安装前须知

1. 面向 HanaAgent 1.3.6-beta，使用官方 `@hana/app-sdk` 1.3.6-beta 构建。
2. 停用同一数据来源的旧 v1 插件，避免重复采集。不要同时启用 v1 与 v2。
3. 从 v1 导入时，先预览，再检查范围和冲突；导入项需要逐条审核后才可参与提示。
4. 当前包尚未经过生产安装、真实会话和生产数据迁移验收。请勿将它当作已经验证的稳定版。
